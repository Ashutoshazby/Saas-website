# Clan Reborn

A premium SaaS agency website for **Clan Reborn**. Built to generate leads through WhatsApp, strategy call booking, service modals, clear project scopes, pricing, FAQ, and legal pages.

## Tech Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- GSAP
- Lucide React
- React Router

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
